Project Overview

Mobile Computer Workstation

A rolling, height-adjustable computer cart that combines a permanent Windows desktop, a quick-connect laptop station, a shared monitor and controls, Apple TV, wireless networking, and battery backup. The goal is to make it easy to roll up, plug in a laptop with one USB-C cable, and switch between systems without rewiring anything.

What this cart does

This is a self-contained mobile workstation. It carries a permanent HP OMEN desktop, but it can also accept a friend's Mac or Windows laptop. The same monitor, keyboard, mouse, network connection, and other USB accessories can be shared between the two computers.

✓
One-cable laptop connection
A compatible laptop connects to the Anker Nano dock with one detachable USB-C cable for video, Ethernet, USB, and charging.
✓
Simple source switching
Video and USB are switched separately for better reliability: the HDMI switch selects the display source, while a dedicated USB switch moves the keyboard, mouse, and shared USB devices between the desktop and laptop.
✓
Wireless uplink, wired inside the cart
The cart joins an existing Wi-Fi network, then distributes that connection over Ethernet to its internal devices.
✓
Battery-backed
The UPS keeps the HP OMEN, monitor, HDMI switch, and USB switch alive during a brief outage so work can be saved and the desktop can shut down cleanly.

How to use it

Use the desktop

Select the HP OMEN on the USB switch, then select the HP OMEN input on the HDMI switch.

Use a laptop

Place the laptop in the cradle, connect one USB-C cable to the Anker Nano dock, select Laptop on the USB switch, then select the Laptop input on the HDMI switch.

Use Apple TV

Select Apple TV on the HDMI switch. The Apple TV remains on the cart network and is controlled with its own remote.

Use another HDMI device

Plug it into the front Extra HDMI connection and select Extra HDMI on the HDMI switch.

Center-post mounting

The VIVO cart's center column appears to be roughly 2–2.3 inches wide from the product image. The white power strip and small electronics should mount only to the stationary lower section so the height-adjustment mechanism can move freely.

Preferred aesthetic: white 6-outlet mountable strip + white/clear mounting hardware where practical, with darker networking, dock, and switching hardware hidden toward the rear of the cart.

Quick glossary

USB switch: A selector that moves shared USB devices such as the keyboard and mouse between the desktop and laptop without switching video.

PoE: Power over Ethernet. It allows some network devices to receive power through the same Ethernet cable that carries data.

PD: USB Power Delivery. This is the charging standard used to power the connected laptop over USB-C.

UPS: Uninterruptible Power Supply. A battery backup that keeps equipment running briefly if wall power drops.

4K at 60 Hz: The shared display path can show a 4K image refreshed 60 times per second.

LiFePO₄: Lithium iron phosphate, a long-life rechargeable battery chemistry used in the UPS.

Extra HDMI: A spare front-facing HDMI input for temporarily connecting another device.
